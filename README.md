# macro-workstation-site

宏观交易工作台的 GitHub Pages 静态部署仓。**本仓库只包含构建产物**，
源码、数据更新脚本、测试和文档位于私有源码仓 `EvanYFM/macro-workstation`，
请勿直接修改本仓库（改动会在下次发布时被覆盖）。

- 线上地址: https://evanyfm.github.io/macro-workstation-site/
- 发布方式: 在私有仓运行 `npm run build:pages && npm run publish`
- `run-manifest.json` 记录每次发布的构建时间与数据日期
